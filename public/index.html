      06 — FAQ
      
Yang sering ditanyakan

    

  

  

    

      
 Apakah wajib login?

      
Tidak. Upload media dan file bisa dilakukan langsung tanpa akun. Login hanya dipakai untuk panel admin internal.

    

    

      
 Apakah file media punya masa kadaluarsa?

      
Tidak. File yang diupload lewat /upload tersimpan permanen. File dari /uploadong punya masa aktif yang kamu pilih sendiri: 1 jam, 24 jam, 5 hari, atau 15 hari.

    

    

      
 Apakah file yang diupload dieksekusi di server?

      
Tidak, tidak pernah. P4DROP murni file hosting. Apa pun ekstensinya, file hanya disimpan dan disajikan sebagai attachment, bukan dijalankan.

    

    

      
 Ada batas ukuran file?

      
Ada, disesuaikan dengan konfigurasi server untuk menjaga stabilitas layanan. Lihat halaman upload untuk batas yang berlaku saat ini.
